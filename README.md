Всем привет! 👋
Хочу представить вам свой менеджер серверов для Assetto Corsa — удобную и полностью автономную программу, созданную для того, чтобы запуск собственного сервера с модами, картами и трафиком занимал пару кликов.
Больше не нужно вручную ковыряться в куче файлов, прописывать конфиги или ломать голову над настройкой. Всё работает автоматически!
Основные возможности программы:
* Управление автопарком и картами: удобный каталог всех машин и трасс из вашей игры.
* Полная поддержка AI-трафика: автоматический поиск и подключение файлов траекторий для масштабных карт.
* Гибкие настройки сервера: быстрая смена портов, паролей, лимитов игроков, физики (ABS, TC), урона и износа шин.
* Визуальный таймлайн погоды и времени суток (CSP WeatherFX): расставляйте точки на шкале 24 часа — дождь, гроза, туман, температура и ветер будут меняться прямо во время игры. Есть готовые шаблоны.
* Live-мониторинг игроков: кто сейчас на сервере, на какой машине, кик и бан в один клик, сообщения всем в чат игры.
* История игроков: кто заходил, сколько раз и сколько времени провёл на сервере.
* Администраторы и доступ: удобный редактор админов, белого и чёрного списков без ручной правки файлов.
* Расписание: плановые рестарты сервера с предупреждениями в чат и автоматические сообщения для игроков (например, ссылка на ваш Discord).
* Диагностика перед запуском: программа сама проверит порты, файлы сервера, трассу и машины и подскажет, что не так.
* Резервные копии настроек: автоматически перед каждым сохранением, вручную в один клик и выгрузка в ZIP. Неудачно что-то поменяли — просто откатитесь.
* Конструктор описания для Content Manager: удобный редактор с поддержкой картинок, ссылок и кликабельных баннеров.
* Менеджер профилей (пресеты): сохраняйте любимые сборки (карта + трафик + машины + погода) и переключайтесь между ними в один клик.
* Модульная консоль: наглядный лог сервера с цветовой индикацией, поиском, фильтром, сохранением в файл и автоперезапуском при вылете.
* Уведомления в Discord: старт и остановка сервера, вылеты и вход игроков.
* Проверка обновлений: программа сама сообщит, когда выйдет новая версия.
* Темы оформления: поддержка тёмной и светлой тем интерфейса.
* Языки интерфейса: поддержка Русского и Английского языка.

Установка:
1. Скачайте и запустите установщик программы.
2. При первом запуске лаунчер сам попытается найти корневую папку с Assetto Corsa. Если не найдёт, укажите её вручную через окно.
3. Программа автоматически скачает с GitHub актуальное ядро AssettoServer, настроит базовые конфиги и будет полностью готова к запуску!
4. Важное уточнение по мультиплееру:
Менеджер поднимает сервер локально на вашем ПК. Чтобы к вам могли подключиться другие игроки, есть два варианта:
— самый простой: программы для создания виртуальной локальной сети, например Radmin VPN или Hamachi;
— для игры через интернет без VPN: пробросьте порты в настройках роутера. Какие именно порты нужны и адреса вашего ПК, покажет кнопка «Диагностика» на главном экране.
Для дождя, ночи и смены погоды у игроков должен быть установлен Custom Shaders Patch (CSP).

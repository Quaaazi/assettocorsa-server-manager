Hi everyone! 👋

I'd like to introduce my server manager for Assetto Corsa — a handy, fully standalone program built so that launching your own server with mods, tracks and traffic takes just a couple of clicks.

No more digging through piles of files, editing configs by hand or racking your brain over setup. Everything works automatically!


Key features:

* Car and track management: a convenient catalog of all cars and tracks from your game.
* Full AI traffic support: automatic detection and setup of spline files for large maps.
* Flexible server settings: quickly change ports, passwords, player limits, physics (ABS, TC), damage and tyre wear.
* Visual weather and time-of-day timeline (CSP WeatherFX): place points on a 24-hour scale — rain, thunderstorms, fog, temperature and wind change right during the game. Ready-made presets included.
* Live player monitoring: see who is on the server and in which car, kick and ban in one click, send messages to everyone in game chat.
* Player history: who joined, how many times and how much time they spent on the server.
* Admins and access: a convenient editor for admins, whitelist and blacklist — no manual file editing.
* Schedule: planned server restarts with chat warnings and automatic messages for players (for example, a link to your Discord).
* Pre-launch diagnostics: the program checks ports, server files, track and cars and tells you what's wrong.
* Settings backups: automatic before every save, manual in one click, and ZIP export. Changed something by mistake — just roll back.
* Content Manager description builder: a handy editor with support for images, links and clickable banners.
* Profile manager (presets): save your favorite setups (track + traffic + cars + weather) and switch between them in one click.
* Modular console: a clear server log with color-coded events, search, filters, saving to file and auto-restart on crash.
* Discord notifications: server start and stop, crashes and player joins.
* Update check: the program lets you know when a new version is out.
* Themes: dark and light interface themes.
* Interface languages: Russian and English.

Installation:

1. Download and run the program installer.
2. On first launch, the launcher will try to find your Assetto Corsa root folder automatically. If it can't, select it manually in the window that appears.
3. The program will automatically download the latest AssettoServer core from GitHub, set up the basic configs and be fully ready to launch!
4. Important note about multiplayer:
The manager runs the server locally on your PC. For other players to connect to you, there are two options:
— the easiest: virtual LAN programs such as Radmin VPN or Hamachi;
— to play over the internet without a VPN: forward the ports in your router settings. The "Diagnostics" button on the main screen shows exactly which ports are needed and your PC's addresses.

Rain, night and weather changes require players to have Custom Shaders Patch (CSP) installed.
